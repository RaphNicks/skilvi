Checks to perform

1 · Document validity

ID number format, expiry date, photo matches the selfie in lighting and angle. Blurry or edited photos → reject with “resubmit” reason.

2 · Identity match

Name on ID vs profile name (middle-name order variations are OK). Mismatch with no explanation → reject.
